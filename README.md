# 🎓 Assistant Rapport de Stage (HTML/CSS/JS)

Cet outil simple, développé en HTML, CSS et JavaScript pur, a été créé pour structurer et rédiger facilement un rapport de stage.

## ✨ Fonctionnalités

* **Structure guidée :** Le rapport est décomposé en sections logiques (Introduction, Entreprise, Missions, Bilan).
* **Journal de bord :** Un onglet dédié permet d'enregistrer les activités jour par jour, avec des repères pour l'insertion de photos.
* **Sauvegarde automatique :** Utilise `Local Storage` pour sauvegarder la progression de la saisie directement dans le navigateur.
* **Export simple :** Un clic génère le brouillon complet du rapport prêt à être copié dans un traitement de texte (Word, Google Docs, etc.).

## 🚀 Utilisation

1.  **Cloner le dépôt :** Clonez ce dépôt sur votre machine locale.
2.  **Ouvrir le fichier :** Ouvrez simplement le fichier `index.html` dans n'importe quel navigateur moderne.
3.  **Rédiger :** Remplissez les champs de chaque onglet. La sauvegarde est automatique.
4.  **Générer :** Allez dans l'onglet "Générer le rapport" et copiez le texte.
